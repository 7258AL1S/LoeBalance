本版本只更新 macOS 应用；Windows 安装包沿用 0.2.0 的原始文件和 SHA-256 校验值。

## 下载哪个

| 平台 | 文件 |
|---|---|
| Apple Silicon Mac（M 系列） | `LoeBalance-macOS-arm64.zip` |
| Intel Mac | `LoeBalance-macOS-x86_64.zip` |
| 64 位 Windows 10 / 11 | `LoeBalance-Setup-0.2.0-win-x64.exe` |
| 32 位 Windows | `LoeBalance-Setup-0.2.0-win-x86.exe` |

每个包都附带对应的 SHA-256 校验文件。

## macOS 更新

- 设置中新增“卡片位置”：左上、左下、右上、右下和自定义。
- 选择自定义后，桌面卡片可以自由拖动，位置会被保存并在下次启动恢复。
- 设置中新增“卡片图层”三档滑块：桌面图标下方、图标与应用之间、所有普通应用窗口上方。
- 预设位置会根据屏幕可见工作区重新计算，并自动夹取到屏幕内。
- 旧版本已有保存坐标的用户会迁移到自定义位置；没有保存坐标的用户默认使用右下。

## Windows

Windows 应用代码和安装包不变。本版本直接复用 0.2.0 的 Windows x64/x86 安装包，不重新构建 Windows。

## 安装与限制

macOS：解压对应架构的 ZIP，把 `LoeBalance.app` 拖入“应用程序”。包使用临时签名，未做 Apple Developer ID 公证；首次启动如被 Gatekeeper 拦截，请在 Finder 中右键选择“打开”。要求 macOS 13 或更高版本。

“所有普通应用窗口上方”使用 AppKit 浮动层级；全屏应用、系统保护窗口或屏保可能仍然覆盖桌面卡片。
