同时发布 macOS 与 Windows 四个安装包。

## 下载哪个

| 平台 | 文件 |
|---|---|
| Apple Silicon Mac（M 系列） | `LoeBalance-macOS-arm64.zip` |
| Intel Mac | `LoeBalance-macOS-x86_64.zip` |

每个包都附带对应的 SHA-256 校验文件，可用 `shasum -a 256 -c xxx.sha256`（macOS）或 `Get-FileHash`（Windows）校验。

## 本次更新

这是 Windows 版首次进入正式发行版：

- Windows 原生应用（.NET 8 / WPF），独立于 macOS 版本，源码只新增在 `windows/` 目录，未修改任何 macOS 实现。
- 托盘图标 + Tooltip + 右键菜单（余额、状态、立即刷新、显示/隐藏桌面卡片、显示/隐藏任务栏余额、设置、退出登录、退出）。
- 任务栏余额读数：紧贴通知区域，右侧预留动画轨道，扣费数字红色、充值数字绿色并向上浮动；余额文字不移动、不震动。
- 桌面卡片：无边框、无任务栏按钮、不抢焦点、不置顶、位于桌面层，支持关/弱/强三档震动、拖动与位置记忆、多显示器工作区夹取。
- 登录与设置窗口：刷新频率 1–3600 秒、震动强度、桌面卡片与任务栏余额开关、开机启动开关、退出登录。
- 网络恢复与系统唤醒立即刷新；429 遵循 Retry-After 并按有界退避重试；401 强制刷新 refresh token 且只重放原请求一次；单实例运行。
- 只把 refresh token 与 user id 存入 Windows 凭据管理器，不保存密码，access token 仅驻留内存。

macOS 应用代码与 0.1.1 相同（本次发布只是同步为 0.2.0 版本号），功能与 0.1.1 一致。

## 安装说明

**macOS**：解压后把 `LoeBalance.app` 拖入「应用程序」。发布包采用临时签名，未做 Apple Developer ID 公证；首次启动若被 Gatekeeper 拦截，请在 Finder 中右键应用选择「打开」。要求 macOS 13 或更高版本。

**Windows**：运行对应安装包即可，按用户安装、无需管理员权限，装到 `%LOCALAPPDATA%\Programs\LoeBalance`，包含开始菜单项、可选的桌面图标与可选的登录时启动，并自带卸载程序。安装包未做 Authenticode 签名，首次运行若被 SmartScreen 拦截，请选择「更多信息 → 仍要运行」。

## 数据与卸载

- Windows：设置与余额快照位于 `%LOCALAPPDATA%\LoeBalance`；凭据存于 Windows 凭据管理器条目 `LoeBalance:sub2api-refresh-token`。交互式卸载会询问是否一并删除这些数据与凭据，静默卸载会保留。
- macOS：设置存于 UserDefaults，凭据存于 Keychain（服务 `cx.loe.LoeBalance`）。

## 验证情况

- Windows：核心单元测试 76 项、平台适配测试 18 项全部通过；GitHub Actions 在 Windows runner 上完成构建、测试与两个架构的安装包编译；真机验证覆盖登录与首次刷新、托盘与任务栏读数、桌面卡片层级与位置记忆、扣费/充值上浮动画、静默安装与卸载。
- macOS：由 GitHub Actions 的 macOS runner 使用 `script/package_release.sh` 构建两个架构，脚本内部完成 `codesign --verify --deep --strict` 与 SHA-256 校验。

## 已知限制

- 两个平台的发布包都未做正式代码签名（Windows 无 Authenticode、macOS 无 Developer ID 公证）。
- 暂无自动更新机制。
- Windows 版在 125% / 150% 与多显示器混合 DPI 场景仍在持续验证中。
